# Documentación, Centeno

Repositorio del robot **Centeno**, microsumo de 5×5×5 cm: **el primer microsumo
de Esdrufao** (~2018). Su nombre viene de que **pesaba 100 gramos**.

## Índice

1. [Hardware y pinout](01-hardware.md), componentes, alimentación y conexionado
2. [PCB](02-pcb.md), esquema `centeno v1.0`, conectores y fabricación
3. [Versiones](03-versiones.md), uWorm (v0), Centeno (v1) y las Hormigas (v1.2)

## Resumen

| | |
|---|---|
| Categoría | Microsumo (máx. 5×5×5 cm; < 100 g) |
| MCU | ATmega328P (Arduino Mini) |
| Motorización | 2× motor + driver L293D |
| Sensores | módulos infrarrojos chinos (regulables) |
| Alimentación | 6 V (`J10`) o batería sobre `RAW` |
| Chasis | chapa metálica cortada (sin modelo 3D) |
| Año de diseño | ~2018 (Esdrufao) |

## Notas

- Centeno fue **el primero** de los microsumos del grupo; de él salieron las
  versiones de los demás (Herculito, "sin gluten", etc.).
- La placa de Centeno se **fresó a CNC** (con **chasis de chapa metálica**). El
  **esquemático de este repo es la v1.0**, tal y como se compartió en el grupo.
